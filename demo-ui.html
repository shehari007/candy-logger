candy-logger@2.2.0 / MIT / TypeScript

A browser console panel that can't crash your app.

Candy Logger shows your logs in a searchable table inside the page. It serializes circular objects, Errors with stack traces, Maps, Sets and BigInts without throwing, and it works under a strict Content Security Policy.

Playground

Each button writes to a live panel built from this repository's dist/ output. Drag it, resize it, filter by level, search and pin rows.

Your browser's devtools console still receives the original objects, so you can compare the two side by side.

Log levels

Six levels, each with its own filter and a live count in the toolbar.

Tags

Coloured labels attached at the call site. Any row can also be tagged from the panel.

Hard-to-serialize values

Inputs that make JSON.stringify throw or silently drop data.

Untrusted input

Every cell is built with textContent. If one of these payloads executed, you would see an alert.

Objects

Collapsed previews that expand into highlighted JSON. Depth and size are capped.

Format specifiers

%s %d %i %f %o %c are applied the way browser devtools apply them.

High volume

Scroll up while logs arrive and the panel keeps your position. Pinned rows are never evicted by maxLogs.

Store and sinks

The store works without a panel, and sinks receive every entry as it is written.

Options

Pick a configuration and apply it. The panel is destroyed and recreated with exactly the options shown on the right.

Flags

destroy() removes the panel, its listeners and its stylesheet, so nothing is left behind after a hot reload.

Usage

The panel is loaded with a dynamic import, so a production build that never enables it does not include it.

Capture console.* 
import { overrideConsole } from 'candy-logger';

const logger = overrideConsole({
  enabled: import.meta.env.DEV,
});

console.log('Hello', { user: 1 });
Use the logger directly 
import { createLogger } from 'candy-logger';

const log = createLogger({ enabled: true });

log.success('Build passed');
log.error(new Error('boom')); // full stack
log.getLogs();                   // works without a panel
Send entries elsewhere 
const off = log.addSink({
  write(entry) {
    if (entry.level === 'error') {
      const body = JSON.stringify(entry);
      navigator.sendBeacon('/api/logs', body);
    }
  },
});

off(); // detach
Without a bundler 
<script src="https://unpkg.com/candy-logger@2"></script>
<script>
  overrideConsole({ enabled: true });
</script>

What's new

Release notes for the last two versions. The full history is in the changelog.

2.2 Panel redesign

  • A new panel design with SVG icons, a neutral palette, and warning and error rows tinted the way devtools tint them.
  • Row actions appear on hover or focus, and are always visible on touch screens.
  • Messages wrap instead of being cut off, short objects show inline, and timestamps include milliseconds.
  • The panel remembers its position, size, minimized state and theme across reloads (persistLayout).
  • An error count in the header, a nonce option for strict style CSPs, and copy buttons that work over plain HTTP.
  • Fixes for a detachUI() race, Firefox exports, and host-page CSS leaking into the panel.

Everything in the box

Table view

Time, level, tags, message and row actions, with per-level filters.

Search

Debounced search over the log data, so text inside collapsed objects still matches.

Pins

Pinned rows stay on top, survive clear() and come back after a reload.

Themes

Dark, light, or auto, which follows the system setting as it changes.

Accessibility

Labelled controls, aria-pressed toggles, a live region and reduced-motion support.

Mobile

A full-screen sheet below 640px wide, and dragging that works with touch.

Sinks

Forward entries to your server, Sentry or a test spy. The panel is one consumer among many.

Export

Download the buffer as JSON or copy every line to the clipboard.

Layout memory

Position, size, minimized state and theme survive a reload, until you change the option in code.

Strict CSP

No inline scripts or handlers. Pass a nonce if your policy also restricts styles.

No dependencies

Nothing to audit beyond the package itself. Ships ESM, CommonJS and a single script file.
